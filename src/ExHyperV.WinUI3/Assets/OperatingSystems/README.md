# 图标来源

这些 SVG 由原 WPF 客户端 `src/ExHyperV.Wpf/Assets/VectorIcons.xaml` 的 `DrawingImage` 资源转换而来，源文件可在 Git 历史中查阅。操作系统名称与 Core 的 `OsImages.SupportedTypes` 对应；`AppIcon.svg` 来自 `Vector.AppIcon`。

转换保留路径、渐变、透明度、裁剪和变换，不依赖 WPF 程序集，也不以位图替代矢量。后续设计直接维护这些 SVG。

资源沿用项目根目录的 LICENSE 及原有权利归属；操作系统图标所代表项目的版权、商标权不因格式转换而改变。
