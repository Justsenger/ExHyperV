## 介绍
ExHyperV 是基于 WinUI 3 打造的 Hyper-V 桌面管理平台，涵盖了个人用户使用 Hyper-V 虚拟机的海量功能。同时，也提供了 AI Agent 使用的 [MCP](src/ExHyperV.Mcp/)。
对于希望集成到工作流的用户，我们还提供了 [ExHyperV.Core](src/ExHyperV.Core/) 和对应的 [API 文档](https://exhyperv.com/api/)。

访问 [ExHyperV.com](https://exhyperv.com) 可获取[系统图鉴（建设中）](https://exhyperv.com/os/)以及软件的在线交互体验。

由于个人精力和硬件环境有限，部分场景可能尚未覆盖。如果在使用中遇到问题或有希望优先支持的功能，欢迎通过 [Issues](https://github.com/Justsenger/ExHyperV/issues) 反馈，或加入群组获得进一步的帮助。
